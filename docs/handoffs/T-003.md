## Decisions I made (proposals for DECISIONS.md)
- **`MODEL_TTS=gemini-3.8-flash-lite-tts` with voice `Orus` on `v1beta`**: faster (2,783 ms vs 3,064 ms for `gemini-3.8-flash-tts`), higher free-tier throughput, returns RIFF `audio/wav` natively, and `Orus` matches the Live coach "Ustaad" voice.
- **Session resumption with single-use ephemeral tokens**: Because `uses=1` consumes the token on the first connect, reconnecting with a `sessionResumption` handle must mint a fresh ephemeral token from the API passing the handle.
- **Free-tier pacing**: Bound Skill Compiler `detail` fan-out to max 2 concurrent Flash calls and batch eval runs to stay within free-tier RPM/RPD.

## Next agent should know
- Ephemeral token creation and Live connect both require `http_options={"api_version": "v1alpha"}`.
- TTS requires `http_options={"api_version": "v1beta"}` and returns `audio/wav` (do not double-wrap WAV headers).
- On sandboxed macOS, set `SSL_CERT_FILE=$(uv run python -c 'import certifi; print(certifi.where())')` to avoid `truststore` Keychain `OSStatus -26276`.
