## What I built
- `services/api/src/parampara/db/jobs.py`: PostgreSQL job queue (`enqueue_job`, `claim_next_job` using `FOR UPDATE SKIP LOCKED`, `complete_job`, `fail_job` with 3 retries and exponential backoff 5 s / 30 s / 120 s, `get_job`).
- `services/api/src/parampara/db/repos/clips.py`: PostgreSQL repository for `clips` (`create_clip_db`, `get_clip_db`, `record_clip_client_metadata_db`, `save_clip_finalized_db`) with server-generated `org/<org_id>/clips/<clip_id>.<ext>` paths.
- `services/api/src/parampara/api/routes/clips.py`: `POST /v1/clips` (returns 10-min signed upload URL), `POST /v1/clips/{clip_id}/finalize` (rejects `blurred=false`, enqueues `finalize_clip` job), and `GET /v1/clips/{clip_id}`; mounted in `api/main.py`.
- `services/api/src/parampara/worker_jobs/finalize_clip.py`: Exemplar job handler (BUILD_PLAN 31.4) — idempotent skip if already finalized, downloads from `clips` bucket, transcodes webm -> H.264/AAC mp4 via `ffmpeg`, probes real `width`/`height`/`duration_ms`/`fps` via `ffprobe`, computes server-side SHA-256, uploads `.mp4`, updates `clips`, emits `trace_events`.
- `services/api/src/parampara/worker.py`: `WorkerRunner` polling loop (1 s interval, `asyncio.Semaphore(2)` max concurrency, 3 retries with backoff, `last_error` + error trace events).
- `services/api/src/parampara/tools/storage.py`: Auto-creates missing bucket on signed upload 400/404 and adds `create_signed_download_url`.

## API changes (for `gen:api`)
- `POST /v1/clips` -> `CreateClipResponse` (`clip_id`, `storage_path`, `signed_url`, `expires_at`)
- `POST /v1/clips/{clip_id}/finalize` -> `ClipResponse` (includes `job_id`)
- `GET /v1/clips/{clip_id}` -> `ClipResponse`
