## What I built
- `apps/web/lib/edge/colour.ts` (exemplar pure TS module): RGB→HSV, 0/360° red hue wrap-around, coloured & dark part profile matching, circle and rectangle pixel-fraction helpers. Zero browser API imports.
- `apps/web/lib/edge/calibrate.ts`: pure `buildZoneCalibration` (default radius 0.06, clamped [0.03, 0.12]), `buildPartProfile` (centre-box sampling, circular median hue, dark-part detection `median_v < 0.25`), and `checkProfileOverlap` (>20% overlap gate).

- Unit tests + benchmark in `apps/web/tests/edge/{colour,calibrate,features,rules}.test.ts`.
