## What I built
- Next.js 16.4.6 App Router app in `apps/web` (React 19.3, TypeScript strict, Tailwind v4.3 tokens per 25.1 in `app/globals.css`, Inter + Noto Sans Devanagari via `next/font`).
- i18n: `lib/i18n/{hi,en}.json`, pure `translate()` and `pickText()`, `useT()` provider; Hindi is the default; the header toggle switches language and is remembered.
- Auth: `lib/auth` (anonymous Supabase sign-in, `POST /v1/demo/join`, `GET /v1/me`), role switcher with all five roles, active role remembered; retryable `error` state when a session exists but the API is unreachable.
- Typed API client: `lib/api/client.ts` (openapi-fetch + bearer middleware); types generated from the API's OpenAPI by `pnpm --filter @parampara/web gen:api` into `packages/contracts/src/openapi/paths.d.ts` (exported as `ApiPaths`).
- Exemplars: page `app/skills/page.tsx` (loading, error with retry, empty, signed-out states) and component `components/ui/StepChip.tsx`. Shared `Button`, `States`.
- Trace drawer: `components/trace/TraceDrawer.tsx` + `lib/trace/sse.ts` (pure SSE parser) + `useTraceStream` (fetch streaming, because `EventSource` cannot send the bearer token; reconnects after 3 s). Right drawer on desktop, bottom sheet on mobile.
- `lib/storage.ts`: localStorage access that never throws (Safari private mode).
